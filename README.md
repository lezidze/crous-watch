# crous-watch

Следит за поиском на trouverunlogement.lescrous.fr и присылает в Telegram каждое новое предложение. Новым считается жильё, которого не было при прошлой проверке, поэтому освободившиеся снова места тоже приходят.

## 1. Telegram-бот

1. В Telegram открой **@BotFather** → `/newbot` → получишь токен вида `123456:ABC...`.
2. Напиши своему боту любое сообщение.
3. Узнай chat_id:
   ```bash
   pip install -r requirements.txt
   TELEGRAM_TOKEN=123456:ABC... python crous_watch.py chat-id
   ```

## 2а. Запуск в GitHub Actions (без своего сервера)

1. Создай **публичный** репозиторий и залей туда все файлы, включая `.github/`.
   - В публичных репозиториях минуты Actions бесплатны и без лимита. В приватных на бесплатном плане 2000 мин/мес, этого хватит только на проверку раз в 30 мин (поменяй cron на `*/30 * * * *`).
   - Секреты в публичном репозитории остаются скрытыми. В `state.json` попадают только публичные данные с сайта CROUS.
2. Settings → Secrets and variables → Actions → **New repository secret**:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT_ID`
3. Actions → crous-watch → **Run workflow** для первого запуска. Придёт сообщение «Мониторинг запущен» со списком текущих предложений.

Ограничения:
- Расписание в Actions не точное: при нагрузке запуск может опоздать на 5–20+ минут.
- GitHub может приостановить расписание, если в публичном репозитории 60 дней не было активности. Тогда просто включи его заново во вкладке Actions.
- Если упавший шаг пишет про права на push: Settings → Actions → General → Workflow permissions → Read and write.

## 2б. Запуск на своей машине (быстрее)

Подойдёт ноутбук, Raspberry Pi или VPS.

```bash
cp .env.example .env      # впиши токен и chat_id
pip install -r requirements.txt
CHECK_INTERVAL=120 python crous_watch.py
```

Скрипт будет проверять сайт раз в 2 минуты (минимум 60 с). После 5 ошибок подряд пришлёт предупреждение в Telegram.

## Другой город или фильтры

Настрой поиск на сайте, скопируй URL из адресной строки и задай его:
- в Actions: Settings → Secrets and variables → Actions → вкладка **Variables** → `CROUS_URL`;
- локально: в `.env`.

`tools/48` в URL — это учебный год 2026–2027. В следующем году номер поменяется, и URL нужно будет обновить.

## Если что-то сломалось

Если CROUS поменяет вёрстку, скрипт не будет молча считать, что предложений ноль. Он завершится с ошибкой «ничего не распознано». В Actions GitHub пришлёт письмо о падении workflow.
